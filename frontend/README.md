# Frontend Portfolio Website

This is the frontend part of the portfolio website built using TypeScript and React. The application is structured to provide a clean and modern user interface, showcasing your achievements, experience, projects, and contact information.

## Project Structure

- **src/**: Contains the main source code for the application.
  - **app/**: Main application components and pages.
  - **components/**: Reusable UI components.
  - **lib/**: Utility functions and API calls.
  - **hooks/**: Custom React hooks.
  - **types/**: TypeScript type definitions.
  - **styles/**: Global CSS styles.
- **public/**: Static files such as your resume.
- **package.json**: Lists dependencies and scripts for the frontend application.
- **tsconfig.json**: TypeScript configuration file.
- **tailwind.config.ts**: Configuration for Tailwind CSS.
- **next.config.js**: Configuration settings for the Next.js application.

## Getting Started

1. **Clone the repository**:
   ```
   git clone <repository-url>
   cd portfolio-website/frontend
   ```

2. **Install dependencies**:
   ```
   npm install
   ```

3. **Run the development server**:
   ```
   npm run dev
   ```

4. **Open your browser** and navigate to `http://localhost:3000` to view your portfolio.

## Features

- Responsive design using Tailwind CSS.
- Smooth animations and transitions.
- Sections for About, Experience, Projects, Achievements, and Contact.
- Custom hooks for theme management and intersection observation.

## Deployment

For deployment, you can use platforms like Vercel or Netlify, which offer free tiers for hosting static sites. Ensure to follow their documentation for deploying Next.js applications.
